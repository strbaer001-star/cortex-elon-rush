# CORTEX RUSH

Browser arcade game by cortex_Ox. Three.js is bundled; no build is required.

## GitHub Pages

1. Create a public repository named cortex-rush.
2. Upload the extracted archive contents, including assets/. Keep index.html in the repository root.
3. Open Settings > Pages. Select Deploy from a branch, main, / (root), then Save.
4. Open the published URL shown under Pages. Players need no GitHub account.

Desktop: A/D or arrows to steer, Space to jump twice, Shift for nitro, S for aerial 360, Q for camera, Esc to pause, R to restart.
Mobile: swipe to steer, tap to jump, swipe down for 360, hold NITRO.
